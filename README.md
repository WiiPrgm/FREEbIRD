# FREEbIRD
This is a homebrew exploit for the Wii Dev Kit menu (known internally as Boot-IRD).
It does not require anything installed on the console, nor does it require any special hardware.

Place the .raw SD card image in the same directory as FREEbIRD.py along with your .elf or .dol Wii homebrew file.
Run the script and write the resulting .raw file to an SD card using a disk imaging program. Dragging and dropping files onto an SD card will not work.

Place the SD card in your dev console, navigate to the Save Data screen and press 'Y' on a Gamecube controller or Wii remote. Exploit will launch the executable baked into the SD card image.
